# Blog cover style

Use the approved Figma thumbnail as the source of truth.

## Canvas

- Size: `1280 × 720`
- Ratio: `16:9`
- Safe outer space: about `56–80 px`
- Background: `#050505`
- Main text: `#F8F8F8`
- Accent teal: `#1B9AAA`
- Soft text: `#B1B1B1`
- Teal may become `#2DACBD` for a brighter detail.

Official logo colors are allowed.

## Type

- Font: `Inter`
- Main title: `Black`, about `110 px`, `112%` line height, `-2%` letter spacing
- Subtitle: `Semi Bold`, about `47 px`, `110%` line height, `-2%` letter spacing
- Use white for most of the title.
- Use teal for one important word or one short phrase.
- Keep the title to two lines when possible.

## Layout

- Put small technology marks near the top left.
- Put the title and subtitle on the left.
- Put the main visual on the right.
- Let the right visual crop beyond the frame when it makes the image feel larger.
- Use one simple teal arrow when it helps connect the title and visual.
- Give the text clear empty space. Do not fill every part of the frame.

## Artwork

- Prefer clean vector logos, UI cards, diagrams, browser panels, and code shapes.
- Use large, simple forms that still read at card size.
- Use a subtle teal glow behind the right visual.
- Use thin white or grey borders where needed.
- Use soft shadows only to separate stacked UI parts.
- Keep details tied to the post topic.

Avoid photos, 3D scenes, decorative noise, many gradients, strong glow around every object, and generic AI artwork.

## Final check

View the cover at both `1280 × 720` and about `320 × 180`. The title and topic must remain clear at the smaller size.
